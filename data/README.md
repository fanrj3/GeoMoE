# Local Data Mounts

Datasets and generated caches are intentionally ignored by the code repository.
The examples assume:

```text
data/
├── VIGOR-M/
│   ├── Pano/
│   ├── level/
│   ├── figures/pano_distribution/pano_distribution_summary.csv
│   └── meta/level_pano/          # generated by prepare_vigor_m_metadata.py
└── justzoomin/
    ├── metadata/
    ├── streetview/images/
    ├── satellite/layout.yaml
    └── satellite/{0,-1,...,-9}/
```

Symlinks are supported, for example:

```bash
ln -s /datasets/VIGOR-M data/VIGOR-M
ln -s /datasets/justzoomin data/justzoomin
```
